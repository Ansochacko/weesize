## Show HN

Title: Show HN: Get any file to the size you need, privately

I built a free, open-source browser app that shrinks PDFs and photos on the device. After the page loads, turn off Wi-Fi and keep working. That is the test I want scrutinized.

There is no account, no paid plan, and no analytics script. Some jobs are not implemented: encryption, true redaction, OCR, and a byte-perfect “fit to size”. Those pages say so instead of returning a fake file. The compressor sets a size goal and will not claim a size it did not reach.

The code is MIT. Please look at the network panel and the worker.
