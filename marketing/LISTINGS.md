# Listings

Submit by hand. Do not imply a user count.

- AlternativeTo, as an alternative to iLovePDF and Smallpdf. Say the difference is local processing, and say what those products do well. Do not upload their logos.
- Privacy-focused software directories. Link the privacy page and the offline test.
- GitHub lists such as awesome-privacy, and self-hosted-style lists only where a static site or a browser app is in scope. Read the list’s rules.
- Open-source directories, after the repository is public.
- PWA directories, after you have installed the page on a phone and checked the icon.

Do not buy a listing that requires a tracking pixel.
