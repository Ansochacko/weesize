# Security

This app processes files in the browser. A vulnerability that sends file bytes off the device, or that stores them in site storage, is in scope.

Report it privately to the maintainer. Do not open a public issue that includes a sample document. Give the version, the browser, and a minimal way to reproduce the problem with a file you created for the report.

There is no bug-bounty fund. There is also no tracking endpoint to disable, because the page does not load one.
